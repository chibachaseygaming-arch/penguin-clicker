# Penguin Clicker

A tiny, self-contained penguin clicker game. Click the penguin to collect fish, buy upgrades, and save your progress in your browser.

## Play

After the first successful deployment, play at:

<https://chibachaseygaming-arch.github.io/penguin-clicker/>

Use the **Download** button on the game page to save a standalone copy as `penguin-clicker.html`.

## Updating the site

The GitHub Actions workflow deploys the contents of the `main` branch to GitHub Pages whenever a change is pushed. The same Pages URL stays in place as the game is updated.

The repository's Pages source must be set to **GitHub Actions** in **Settings → Pages** for the first deployment.
