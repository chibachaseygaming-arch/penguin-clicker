# Penguin Clicker

A tiny penguin clicker game that can also be installed as an offline-ready app. Click the penguin to collect fish, buy upgrades, and save your progress in your browser.

## Play

Play at:

<https://chibachaseygaming-arch.github.io/penguin-clicker/>

Use **Download app** on the game page to download an app bundle ZIP. It contains the game, installable-app files, icons, and installation instructions. **HTML** downloads the game as a single file you can open directly.

To install the app on your device, open the game website in Chrome or Edge and choose **Install app**. On iPhone or iPad, use **Share → Add to Home Screen**. Once installed, the game works offline.

## Updating the site

The GitHub Actions workflow packages both downloads and deploys the site whenever changes are pushed to `main`. The same Pages URL stays in place as the game is updated.

GitHub Pages is configured to use **GitHub Actions**.
